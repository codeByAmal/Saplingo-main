## 📌 About The Project

**Saplingo** is a web-based e-commerce application developed using **PHP and MySQL**.

The platform provides users with an online shopping experience where they can browse products, manage their profiles, add products to a shopping cart, and proceed through the checkout process.

The project also includes administrative functionality for managing products, users, orders, and other website operations.
