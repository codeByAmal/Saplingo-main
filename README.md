# 🌱 Saplingo

Saplingo is a PHP and MySQL based web application designed to provide an online shopping experience with user and administrative features.

👉 **[Visit Saplingo](https://saplingo.ct.ws/)**

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

## ✨ Features

### 👤 User

- User registration
- User login and logout
- User profile
- Browse products
- Shopping cart
- Checkout
- Contact/feedback functionality

### 🔐 Admin

- Admin login
- Manage users
- Manage products
- Manage orders
- Manage website content

## 🗄️ Database

The project uses **MySQL** as its database.

The database SQL file is available in the `DB` folder.

## 🚀 Running Locally

### Requirements

- XAMPP
- Apache
- MySQL
- PHP

### Setup

1. Clone or download the repository.

2. Place the project inside:

   `C:\xampp\htdocs\`

3. Start **Apache** and **MySQL** from XAMPP.

4. Create a MySQL database named:

   `saplingo`

5. Import the SQL file from the `DB` folder using phpMyAdmin.

6. Configure the database connection in the PHP files.

7. Open:

   `http://localhost/Saplingo-main/`
